Maybe useless program, you have to drag any file on top of the exe file until (on windows) there is a little box saying "+open with executor(version).exe":

File type	What happens
.exe	Runs normally
.bat / .cmd	Executes
.msi	Opens installer
.txt	Opens in default editor
.png / .jpg	Opens in Photos
.zip	Opens in Explorer
.pdf	Opens in default viewer
ANY OTHER FILE	Windows opens it with the default app
